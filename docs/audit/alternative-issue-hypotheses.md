# 다른 시각의 현안 정리

> 출원 프로세스의 규정·제도 자체보다 **단계 사이의 정보·권리·판단 유실, 이해상충, 관행적 운영**에서 발생할 수 있는 예상 현안을 정리한다.  
> 아래 항목은 문제로 단정하지 않고 **거증이 필요한 감사 가설**로 활용한다.

## 1. 발명 발굴

| 예상 현안 가설 | 확인 포인트 / 거증 방법 |
|---|---|
| 실질 발명자 누락·과다 등재 | 직발서 작성이력, Project 참여자와 대표·공동발명자 비교 |
| 동일·유사 기술 반복 출원 | 발명자·제목·초록·청구항의 AI 유사도 및 신고시점 분석 |
| KPI·보상 Cut-off 전 발명신고 집중 | 월별 신고건수와 평가·보상 기준시점 비교 |
| 특허보다 영업비밀이 적합한 기술 출원 | 공정 Recipe 등 외부 관찰·침해입증이 어려운 특허를 기술전문가가 검토 |

## 2. 출원 평가·등급 심의

| 예상 현안 가설 | 확인 포인트 / 거증 방법 |
|---|---|
| 발명자와 심의위원 간 이해상충 | 대표·공동발명자 사번과 심의위원 사번 Mapping |
| 평가위원 전문분야와 심의대상 기술 불일치 | 위원 전공·경력·기존 특허와 평가대상 기술분류 비교 |
| 최초 추천등급이 최종평가를 Anchoring | 연구조직 추천등급과 위원별 점수·최종등급 비교 |
| 평가자료 작성 수준이 등급에 영향 | 자료 분량·첨부자료 수와 평가결과의 관계 분석 |

### 실제 발견 사례에서 확장할 관점
- 공동발명자가 본인 관련 특허의 심의위원으로 참여하는지
- 동일 조직·동일 Project 관계자가 평가하는지
- 위원 간 상호평가 관계가 반복되는지
- 특정 위원의 참여 여부에 따라 고등급 비율이 유의하게 달라지는지

## 3. 명세서·청구항 작성

| 예상 현안 가설 | 확인 포인트 / 거증 방법 |
|---|---|
| 발명자가 승인한 최종본과 실제 제출본 불일치 | 발명자 최종 승인 Version과 특허청 제출본 Diff |
| 외부대리인의 명세서·Claim Template 과다 재사용 | 동일 대리인 작성 특허 간 문장·Claim 구조 유사도 |
| 발명자의 특허 이해도 차이로 불필요한 Claim 한정 발생 | 직발서 → 대리인 초안 → 발명자 의견 → 최종 Claim 추적 |
| 국내 명세서와 해외 영문본 간 의도치 않은 내용 괴리 | 동일 Family의 KR-US 명세서·Claim 비교 |

## 4. 국내 출원

| 예상 현안 가설 | 확인 포인트 / 거증 방법 |
|---|---|
| 출원처리 지연에 따른 Priority·공개 Risk | 접수→담당자 배정→초안→검토→출원 Lead Time 분석 |
| 논문·학회·제품공개보다 출원이 늦은 사례 | 출원일과 외부 공개일 비교 |
| 출원담당자별 처리량과 품질 간 편차 | 담당자별 처리건수 × OA × Claim 축소 × Lead Time 비교 |

## 5. 해외 출원

| 예상 현안 가설 | 확인 포인트 / 거증 방법 |
|---|---|
| 최초 등급만으로 해외출원 여부가 사실상 자동 결정 | 최초등급과 12개월 시점 해외출원 결정근거 비교 |
| 시장·경쟁환경과 무관한 관성적 국가 Set 출원 | 기술분야별 US/CN/EP 등 출원국 Pattern 분석 |
| 선제 영문화 후 실제 해외출원 미진행에 따른 비용 비효율 | 영문화 건수·비용과 실제 해외출원 전환율 비교 |
| PCT 국제조사·시장변화가 국가단계 진입 결정에 미반영 | ISR/견해서와 국가단계 진입·포기 의사결정 비교 |

## 6. 심사·OA 대응

| 예상 현안 가설 | 확인 포인트 / 거증 방법 |
|---|---|
| 발명자 확인 없이 핵심 Claim 축소 | OA Amendment와 발명자 검토·승인 History 비교 |
| 등록률·처리기간을 위해 과도하게 좁은 Claim으로 조기 등록 | Final OA/NOA 전후 독립항 변화와 담당자별 등록률 분석 |
| 담당자별 RCE·Appeal·포기 전략 편차 | 등급·기술분야를 보정한 담당자별 RCE/Appeal/포기율 |
| 동일 Family의 국가별 Claim이 전략적 이유 없이 상이 | KR/US/CN/EP 최종 Claim과 국가별 대응사유 비교 |

## 7. 등록·후속 권리화

| 예상 현안 가설 | 확인 포인트 / 거증 방법 |
|---|---|
| 높은 등록률이 실질적인 권리범위 축소를 은폐 | 최초 독립항과 등록 독립항의 필수 구성요소 변화 분석 |
| 추가 권리화 가치가 있는데 Continuation·분할 미활용 | 고등급 특허의 최초 명세서와 Family/후속출원 비교 |
| 실질적 추가가치가 낮은 Continuation·분할 반복 | Continuation Chain별 Claim 차별성과 출원 목적 검토 |

## 8. 유지·Portfolio 관리

| 예상 현안 가설 | 확인 포인트 / 거증 방법 |
|---|---|
| 최초 고등급이 현재 가치와 무관하게 유지결정에 고착 | 최초등급 × 현재 제품/Roadmap × 유지비 비교 |
| 발명자·최초 출원담당자가 자신의 특허 유지 필요성을 평가 | 발명자/출원담당자와 유지·포기 평가자 Mapping |
| 국가별 권리 실효성 차이에도 전체 Family를 관성적으로 유지 | 국가별 Claim Scope·사업가치와 연차료 비교 |
| OA·포기·권리축소 결과가 앞단 프로세스에 Feedback되지 않음 | 반복 발생 기술/대리인/담당자 이슈와 평가·배정기준 개선이력 비교 |

## 9. 공통 분석 프레임

각 단계에서 단순히 **“규정대로 처리했는가?”**만 확인하지 않고 아래 흐름의 화살표마다 정보·판단·권리가 유실되거나 왜곡되는지 확인한다.

**직발서 → 출원평가 → 명세서 → 최초 Claim → OA → 최종 Claim → Family → 유지**

### Role Collision
서로 견제되어야 할 역할을 동일인이 동시에 수행하는지도 별도 점검한다.

- 발명자 = 심의위원
- 출원담당자 = 등급평가자
- 최초 출원담당자 = 유지·포기 평가자
- 명세서 작성자 = 품질평가자
- 해외출원 추천자 = 최종 승인자

!!! note "활용 원칙"
    각 항목은 현안으로 단정하지 않고 전수 Data 또는 표본 Case로 이상징후를 선별한 뒤, 원본자료·시스템 History·인터뷰를 통해 실제 원인과 통제 미흡 여부를 거증한다.
